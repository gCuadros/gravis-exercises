# Compatibility note — 0.4.0

B001 Group B adds eight draft exercises and seven vocabulary keys. The pre-1.0 minor increment signals expanded closed unions to exhaustive TypeScript consumers and validators. This is an unreleased preview, not registry publication or technical approval.

| Namespace | Added keys                                                               |
| --------- | ------------------------------------------------------------------------ |
| Equipment | `rings`, `kettlebell`                                                    |
| Families  | `overhead_press`, `horizontal_row`, `kettlebell_swing`, `lunge`, `carry` |

Record/envelope generation remains 2 and taxonomy shape generation remains 1. All previous IDs, slugs and record bytes are preserved. No identity redirect or history migration is required.

1. Take data, schemas, vocabulary and generated declarations from the same archive. Older closed enums reject the new equipment/families.
2. Extend exhaustive maps and filters, or derive labels/options from the taxonomy exports. A shared family is not a shared exercise history: Romanian/conventional deadlifts, supinated/pronated pull-ups and ring/barbell rows remain distinct identities. Machine rowing still uses `ergometer_row`.
3. Honor recording notes. Reverse lunges count total repetitions across both legs. The suitcase carry requires the mass of one bell and measured distance, with optional walking duration; track left/right sets in the consuming app. There is no new per-side field or automatic step-to-distance conversion.
4. Ring height/body angle are setup notes, not invented assistance weights. Kettlebell load is one bell; barbell loads include bar and plates.
5. Opt into `/preview` for these drafts. Default imports and published JSON still exclude them. Search can return more matches; select by a deliberate identity.
